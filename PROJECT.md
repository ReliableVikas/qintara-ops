# Qintara Ops

Version: v1.0 (Development)

---

# Vision

Qintara Ops is the internal operating system for Qintara Living.

Its purpose is simple:

- Save Time
- Reduce Human Errors
- Standardize Operations
- Replace Memory with System

The software should remember operational tasks so people don't have to.

Every feature must solve a real business problem.

If a feature doesn't save time or reduce mistakes, it should not be added.

Owners

Sales Team

---

## Caretaker

Can only access assigned properties.

Can:

- View Upcoming Bookings
- View Today's Check-ins
- View Today's Check-outs
- Call Guest
- Upload Guest Documents
- Collect Balance
- Mark Guest Checked In
- Mark Guest Checked Out

Cannot:

- Create Booking
- Edit Booking
- View Other Properties
- Access Settings

# Development Rules

Never edit Production directly.

Every feature must be developed in Development first.

Every release must be tested.

Every release must be committed to GitHub.

Never add features that don't solve a real business problem.

Keep the UI simple.

Speed is more important than fancy design.
